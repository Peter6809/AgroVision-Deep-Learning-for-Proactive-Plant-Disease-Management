# 🌿 AgroVision: Deep Learning for Proactive Plant Disease Management

AgroVision is a deep learning-based research project focused on proactive plant disease detection and management. The goal is to empower farmers and agricultural stakeholders with intelligent tools to detect diseases at early stages, minimizing crop loss and maximizing yield.

This project presents a **comparative analysis** of four powerful deep learning architectures:
- **VGG16**
- **Recurrent Neural Networks (RNN)**
- **Capsule Networks**
- **Vision Transformers (ViT)**

All models are trained and evaluated on a comprehensive dataset containing **87,000+ RGB images** across **38 plant disease categories**, enabling robust performance comparison.

## 🧠 Key Features
- 📊 **Model Benchmarking:** Comparative study of different deep learning models for plant disease classification.
- 🌱 **Real-World Dataset:** Augmented dataset with diverse plant disease images captured in natural conditions.
- 🔬 **Experimental Evaluation:** Accuracy, precision, recall, F1-score, and inference time used for performance assessment.
- 🤖 **Intelligent Integration:** Designed for integration into smart farming tools, including mobile applications and chatbot interfaces.
- 📈 **Proactive Management:** Early disease detection enables better decision-making and efficient pest control.

## 🔍 Models Used
| Model            | Strengths                                   |
|------------------|----------------------------------------------|
| **VGG16**        | Simple yet powerful CNN with good baseline performance |
| **RNN**          | Sequential modeling, useful for time-series disease progression |
| **CapsuleNet**   | Captures spatial hierarchies and relationships |
| **Vision Transformer** | State-of-the-art accuracy on image classification tasks |

## 📁 Dataset
- Total Images: **87,000+**
- Classes: **38** (including healthy and diseased leaves)
- Format: RGB images, preprocessed and augmented for deep learning

## 🚀 Future Scope
- Deployment in **web and mobile platforms**
- Integration with **chatbot assistants** for real-time farmer support
- Expansion to **multi-class disease severity prediction**

## 📜 Research Goals
This project supports a research paper aiming to highlight strengths and trade-offs of different DL models in agricultural use cases. Results will guide future developments in smart agriculture technologies.
